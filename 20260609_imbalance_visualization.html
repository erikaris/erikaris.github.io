Situation 3 — Focal loss: how much the model learns from each class

Focal loss does not change the data distribution. It changes how much gradient each class contributes during training. Blue = cross-entropy (no reweighting). Green = focal loss at the selected γ value.

FL(p_t)  =  −(1 − p_t)γ × log(p_t)     where p_t = model's predicted probability for the correct class
Focusing parameter   γ  = 2.0 recommended default (Lin et al., 2017)
Blue — cross-entropy (γ=0): no reweighting, majority class dominates Green — focal loss (current γ): easy samples down-weighted, minority classes prioritised

Gradient contributions estimated using assumed per-class model accuracy at convergence: majority class p=0.85, scaling down to p=0.15 for the hardest minority class.

Key insight: With cross-entropy at 196:1 imbalance, Promoting/selling contributes ~40% of the total gradient — even though the model already classifies it well. Incentivising (n=6) contributes only ~2%. With focal loss (γ=2), the model's attention shifts: hard minority class examples retain their gradient while easy majority examples are down-weighted toward zero. Drag the slider left (γ→0) to see the distribution collapse back to cross-entropy behaviour.
Why use both data collection AND focal loss?
Data collection (Situations 1→2) reduces the raw distributional skew in the training data. Focal loss (Situation 3) corrects the learning dynamics during training. Neither strategy alone is sufficient for severe imbalance: collection alone cannot fully equate class frequencies without impractical annotation effort; focal loss alone cannot compensate for classes with fewer than 10–30 samples, where even up-weighted gradients carry too little signal. Together, the strategies are complementary.
